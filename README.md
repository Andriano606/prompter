# Prompter

Суфлер для Ubuntu / GNOME (Wayland). Сценарій пишете в головному вікні. Текст показується в напівпрозорому вікні **поверх усіх програм**, крізь яке видно все, що під ним. Сторінки гортаються глобальними гарячими клавішами, навіть коли активний Zoom чи браузер.

## Встановлення

```bash
./install.sh              # програма, іконка, ярлик у меню, розширення GNOME Shell
./install.sh --uninstall  # видалити (налаштування в ~/.config/prompter лишаються)
```

Після **першого** встановлення вийдіть із сесії й увійдіть знову: GNOME на Wayland завантажує нові розширення лише так. Доки розширення не активне, програма показує про це банер.

Потрібні лише пакети, які вже є в Ubuntu: `python3-gi`, GTK 4 і libadwaita.

## Як це влаштовано

| Частина | Файл | Що робить |
|---|---|---|
| Програма (GTK 4 + libadwaita) | `prompter.py` | Редактор сценарію, вікно суфлера, налаштування, запис комбінацій клавіш, CLI |
| Розширення GNOME Shell | `extension/` | Тримає суфлер поверх вікон і на всіх робочих столах, не дає йому забирати фокус, запам'ятовує його положення, перехоплює глобальні клавіші |

На Wayland звичайна програма не може ні тримати своє вікно поверх інших, ні перехоплювати клавіші в інших програмах. Тому це робить розширення, як у window-presets. Комбінації зберігаються в `~/.config/prompter/shortcuts.json`. Розширення стежить за цим файлом і за кожною комбінацією викликає дію програми через D-Bus (`org.gtk.Actions` на `org.andrii.Prompter`).

## Сценарій і сторінки

Нова сторінка — кнопка **«+ Нова сторінка»** внизу редактора (або **Ctrl+Enter**). Вона додається одразу після сторінки, де стоїть курсор. У самому тексті сторінки розділяє рядок `---` (у редакторі він сірий і по центру), тож можна писати його й вручну. Сценарій — звичайний `.md` / `.txt`:

```
# Вступ
Привіт! Мене звати **Андрій**.
// примітка для себе: дрібна і сіра

---

Наступний блок…
```

Поточна сторінка в редакторі підсвічена. Суфлер показує ту сторінку, на якій стоїть курсор, а при гортанні клавішами редактор прокручується до неї. Редактор зберігає зміни автоматично. Файл можна правити й в іншому редакторі: зміни підхопляться. Для кожного файлу запам'ятовується блок, на якому ви зупинилися.

## Клавіші (Mac-клавіатура: ⌃ Control, ⌥ Option, ⌘ Cmd)

| Типово | Дія |
|---|---|
| ⌃⌘→ / ⌃⌘← | наступна / попередня сторінка |
| ⌃⌘↓ / ⌃⌘↑ | прокрутити довгу сторінку |
| ⌃⌘H | показати / сховати суфлер (якщо програма закрита — запустити) |
| ⌃⌘L | закріпити / відкріпити: кліки проходять крізь суфлер |
| ⌃⌘= / ⌃⌘− | розмір шрифту |

**Свої комбінації** — кнопка ⌨ у заголовку (або підказка з клавішами внизу редактора, або меню → «Гарячі клавіші»). Клацніть на дію й натисніть потрібну комбінацію; поки ви її записуєте, глобальні клавіші вимкнені, тож можна записати навіть ту, що вже призначена. Без модифікатора можна призначити PageUp / PageDown (так працюють презентаційні клікери) і F1–F24. Після збереження програма попросить натиснути комбінацію й покаже «✓ працює»; якщо її вже зайняла інша програма — підсвітить рядок червоним. Там же, у «Налаштуваннях», шрифт, прозорість і вирівнювання.

**Клавіші працюють, поки Prompter запущений.** Закриття вікна редактора лише ховає його — програма й суфлер лишаються у фоні. Повернути редактор — «Prompter» у меню програм; вийти зовсім — меню → «Вийти» (Ctrl+Q). Якщо програма закрита, ⌃⌘H її запускає.

Суфлер перетягується за середину, а розмір змінюється за будь-який край чи кут, включно з куточком ◢; курсор над краєм стає стрілкою. Положення запам'ятовується. Коли суфлер у фокусі, працюють `→ ← Space ↑ ↓ + −`, а `Esc` ховає його.

З терміналу: `prompter next|prev|down|up|toggle|show|hide|lock|bigger|smaller|new-page|shortcuts|reload|preferences|quit`.

## Щоб Zoom / Loom не бачили текст

У GNOME немає системного способу виключити вікно із запису екрана. Тому:

- **Діліться вікном, а не екраном** (браузер, презентація). Суфлер поверх нього в трансляцію не потрапляє, бо Zoom/Loom беруть лише вміст вибраного вікна.
- **Або два монітори:** суфлер на одному, а транслюєте інший.

Якщо ж транслювати весь екран, на якому стоїть суфлер, його буде видно.

## Тести

```bash
python3 -m pytest                               # юніт-тести (швидкі)
python3 -m pytest -m integration -o addopts=""  # у прихованому headless GNOME Shell (~15 с)
python3 -m pytest -o addopts=""                 # усе
```

Інтеграційний тест запускає окремий `gnome-shell --headless` зі своїм D-Bus і розширенням з цієї папки. Ваш робочий стіл він не зачіпає.
